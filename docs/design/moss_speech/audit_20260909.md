## Text decoding contract (R6)

The service decodes the entire generated text channel, filters special tokens,
performs the existing empty/end-empty replacements, and withholds trailing
U+FFFD replacement characters (a truncated Unicode suffix). Both terminal modes
use this rule. No grid rows or usage tokens are removed. This suffix policy is
explicit and can also omit a literal trailing U+FFFD; it does not promise recovery
of malformed text bytes.

New HF exports keep upstream `grid[:-1]` decoding in `text` and independently
export `service_text` plus `text_decode_profile=moss-full-grid-unicode-prefix-v1`.
Native exports mark that profile. Pair checks expose `grid_cases` and `text_cases`;
unknown/mismatched profiles fail. Unversioned frozen references continue to compare
their original text strictly. Re-export into a fresh directory to adopt the profile;
never patch an old report. WER/CER uses the declared comparison text. HTTP length
probes use prefixes of the frozen independent HF grid and record both strings;
they verify service text/finish/usage, not an HTTP-visible native raw grid.
